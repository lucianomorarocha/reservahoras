# Reserva de Horas Médicas - DevOps Integrador

Este servicio es una página web estática administrada con Nginx mediante Docker. No utiliza bases de datos ni expone datos sensibles.

## Ejecución Local
1. Instalar Docker Desktop.
2. Clonar el repositorio.
3. Ejecutar: `docker compose up -d`
4. Ingresar en el navegador a: `http://localhost:8080`
5. Detener el servicio: `docker compose down`
